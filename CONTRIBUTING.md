# Contributing to PiGallery2

PiGallery2 is a hobby project with a single maintainer, done in free time next to a day job and a family:
about 1-2 releases and 4-5 medium features a year.

- **Bug fixes** are welcome. Please open an issue first, or link the existing one.
- **New features** have a low chance of being reviewed. To keep the app simple, check first whether the feature can be done
  1. with an existing [setting](https://bpatrik.github.io/pigallery2/user-guide/configuration),
  2. with a theme (custom CSS, `Gallery.Themes` setting),
  3. or with an [extension](https://bpatrik.github.io/pigallery2/development/extensions)
     (extensions can also change the settings and the theme).

  If the extension API is missing something, a PR that improves it is welcome.
  Otherwise, open an issue and discuss it with the maintainer before writing code.

Read the full [contribution guide](https://bpatrik.github.io/pigallery2/development/contributing) to get started.
Using an AI coding agent? See [AGENTS.md](AGENTS.md).
