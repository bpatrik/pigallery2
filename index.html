    PiGallery2

    A fast, directory-first, self-hosted photo gallery, built for low-resource servers like the Raspberry Pi. Point it at your photo folder and browse it as it is: PiGallery2 never modifies your photos.

    Get started Try the live demo

    The demo server sleeps when idle, so the first load may take up to 60 seconds.
